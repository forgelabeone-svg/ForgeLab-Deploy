# Készíts egy böngészős 2D arcade játékot "Orbit Drift" néven, HTML5 Canvas + vani

Generated by ForgeLab.

## Tech stack

static

## Features

- HTML5 Canvas + vanilla JS single-page app, no external libraries or backend
- Spaceship with velocity vector affected by Newtonian gravity from planets (force = G * mass / distance^2)
- Limited thrust impulses per level (5–10) aimed via mouse position or WASD/arrow keys
- Game over on planet collision (with explosion/particle effect) and on leaving playfield bounds
- Win condition: reach the portal/gate, then advance to next level
- At least 5 hand-designed levels with increasing difficulty (more planets, tighter paths, moving planets in later levels)
- Bronze/silver/gold rating per level based on par time or par thrust count
- Ship trail (last ~30–50 positions, fading line or dots)

## Getting started


Open index.html directly in your browser, or run:
npx serve .
