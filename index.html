Quick Start Commands
Setup Python environment
python3 -m venv .venv && source .venv/bin/activate && pip install -r requirements.txt
Configure environment
cp .env.example .env
Run healthcheck
python main.py healthcheck
Get order statuses
python main.py get-order-statuses
Get orders (limit 10)
python main.py get-orders --limit 10
Get products (limit 5, active only)
python main.py get-products --limit 5
Start local API bridge (port 8000)
python main.py serve --port 8000

Chrome Extension

Smart Tab Manager — Manifest V3 Chrome Extension for BEOCIA Kft. developer workflow.

Installation Guide
  1. Open chrome://extensions in Chrome
  2. Enable Developer Mode (top-right toggle)
  3. Click Load unpacked
  4. Select the chrome_extension/ folder from this project
  5. The Smart Tab Manager icon will appear in the Chrome toolbar
  6. Click the icon to open the popup
  7. Verify the tab list is visible and functional
CSP Compliance Checklist
✓ No inline scripts in popup.html
✓ No inline event handlers (onclick, onload, etc.)
✓ No external CDN resources
✓ popup.js is a separate file
✓ popup.css is a separate file
✓ background.js is a service worker
✓ Manifest V3 format
✓ Icons at 16/32/48/128px
✓ Permissions: tabs, storage, activeTab
✓ All chrome.* calls wrapped in try/catch
